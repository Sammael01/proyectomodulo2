# HotelVista

Comparador de precios de hoteles. Angular 22, Bootstrap 5, Animate.css y Font Awesome.

## Requisitos

- Node.js 24 LTS (24.15 o superior)

## Uso

```
npm install
npm start
```

Abrir http://localhost:4200
