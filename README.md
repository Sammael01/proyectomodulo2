# HotelVista

Angular 22 (NgModule) + Bootstrap 5 + Font Awesome + animate.css (por CDN en `src/index.html`).

    npm install
    npm start      # http://localhost:4200
    npm test       # vitest

Los datos están en `public/data/alojamientos.json` y se leen con `Alojamientoservice`.
Para usar una API real, cambia `URL_BASE` en `src/app/services/alojamientoservice.ts`.
